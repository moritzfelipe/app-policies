rclone backup

A personal, single-user Google API client used with the open-source tool rclone to back up files from the owner's own computer to the owner's own Google Drive.

It is not a public service. It is used by one person, for their own data only.

  • Requested access: https://www.googleapis.com/auth/drive.file, meaning only the files this app itself creates.
  • Files are encrypted on the owner's computer before upload.
