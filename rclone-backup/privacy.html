Privacy policy: rclone backup

Last updated: 2026-09-28

"rclone backup" is a personal, single-user Google API client. It lets the open-source tool rclone back up the owner's files to the owner's own Google Drive.

What Google data it accesses

It requests only the https://www.googleapis.com/auth/drive.file scope. With this scope the app can only see and manage files and folders that it created itself. It cannot see any other file in the user's Google Drive.

How the data is used

  • The data is used solely to store, list, verify, and restore the user's own backups.
  • Files are encrypted on the user's computer before upload. They are stored only in the user's own Google Drive.
  • No Google user data is collected, stored, or processed by the developer on any other server.

Sharing

Google user data is not shared with, sold to, or transferred to any third party.

AI and machine learning

Google user data is not used to develop, improve, or train any AI or machine-learning model.

Compliance

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
